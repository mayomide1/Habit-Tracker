# Habit Tracker
A simple web app for building daily habits. Add habits, check them off each day, and watch your streak grow. Miss a day and the streak resets. Everything is saved in your browser.

## Features

- Add new habits
- Check habits off once per day
- Streak counter with fire emoji 🔥
- Streak resets when a day is missed
- Delete habits you no longer want
- Data persists across sessions via localStorage
- Responsive, clean gradient UI

## How to Use

1. Click **Add Habit** to reveal the input field.
2. Type your habit and click **Save Habit**.
3. Click **Check** each day to mark the habit complete and grow your streak.
4. Click **✕** to delete a habit you no longer want to track.

## Stack

- **HTML** – structure
- **CSS** – styling (gradient background, card-based habit list, responsive layout)
- **JavaScript** – logic, DOM manipulation, event delegation
- **localStorage** – persistence
